Create an automated workflow using standard free Google Workspace tools:

  3. Use Google Apps Script (free built-in automation) to automatically send approval emails to managers.
  4. Embed a Looker Studio dashboard for L&D metric visualization.
Option 3: Microsoft 365 (Forms + Power Automate)

If your organization already uses M365:

  • Use MS Forms for front-end entry.
